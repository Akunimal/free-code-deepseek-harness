# Release notes template

Every GitHub release description must contain both language sections below.
Keep the same facts, links, and artifact list aligned between the two sections.

## English

- Summarize the user-visible changes.
- List verification and the published artifacts.
- State that the release was built and uploaded manually.

## Español

- Resumir los cambios visibles para el usuario.
- Listar la verificación y los artefactos publicados.
- Indicar que la release se compiló y subió manualmente.
